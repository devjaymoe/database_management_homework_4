# database_management_homework_4
Pizza php application

To use the applicaiton, you only need to go to the index page to view all data in the database.

To add data in the database, select the "Add pizza button". This will take you to a form to complete to add data into the database.

Once you fill in all information, select "Submit" and the information will be put into the database.

If the submission was successful, you will be redirected to the index page which will display all the database information again.
